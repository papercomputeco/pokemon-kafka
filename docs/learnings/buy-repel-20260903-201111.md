## What v1/v2 burned, so we stop guessing (the actual reason to stop)

1. **The room background permanently decodes as `MONEY / BUY 87400 / SELL / QUIT /
   Thank you!`** (rows 0–5, 14). It moves with the player (probe: (2,5)→(2,7) with the rows
   unchanged). Any row-text predicate on those words is polluted; **registers (0xCC26/0xCC28/
   0xD125) + money + bag deltas are the only truth**. `qm.in_shop_tx` is unusable here.
2. **A-spam through a flow buys.** v1's 30-blind-A loop bought 3× ULTRA and parked in the
   *SELL* band. Every v3 round is: 1 unit, confirm only on money drop AND bag delta naming the
   target id; any other gain aborts with screenshot.
3. **`rig.settle()` with a parked box facing the NPC wedged the START menu** (v2 crash, and
   settle's own docstring warns about this: "A settle leading with A can open the very thing
   it's trying to close"). Never `settle`/`bank` while a box is up in front of the clerk.
4. **The goodbye "Thank you!" box (id 1) is ghost-like**: A and B are no-ops with us facing the
   clerk, movement still works under it, and boot+bank proceed fine. It is boot-safe; don't
   fight it.
5. **`bag_named(named=...)` was the v2 crash signature** — no such kwarg; it's `bag_named(full=True)`,
   and `bag()` / `bag_named()` read-only paths never mutate. (The crash itself: a Python
   TypeError in the leg's own predicate, not the game.)
